## О проекте

**TeamFinder** объединяет тех, у кого есть идея проекта, и тех, кто хочет присоединиться к команде.

Пользовательский сценарий строится вокруг профиля, навыков и конкретной роли в проекте. Владелец проекта определяет потребности команды и рассматривает заявки, а кандидат выбирает подходящие роли и видит объяснение соответствия своих навыков требованиям.

## Scope v1

> Ниже описан целевой объём первой версии. Перечень не является отчётом о готовности функций.

| Направление | Что входит в первую версию |
| :--- | :--- |
| **Аккаунт и профиль** | Регистрация, вход, профиль пользователя, навыки и интересующие роли |
| **Проекты** | Создание и просмотр проектов, роли в команде и количество мест |
| **Требования к ролям** | Обязательные и желательные навыки — required и nice-to-have |
| **Объяснимый matching** | Сопоставление навыков пользователя с требованиями конкретной роли |
| **Заявки** | Подача, рассмотрение, принятие, отклонение и отзыв |
| **Команда** | Участие через Membership и управление составом команды |
| **Жизненный цикл** | Черновик, набор участников, работа над проектом, завершение или отмена |

### Основной сценарий

```text
Профиль и навыки → Поиск проекта → Выбор роли → Matching
                                                   ↓
                            Команда ← Решение ← Заявка
```

### Принципы формирования команды

- **Заявка ≠ участие.** Application не занимает место; capacity учитывает Membership.
- **Одна заявка на конкретную роль.** При этом можно подать заявки на разные роли одного проекта.
- **Принятие создаёт участие.** Остальные ожидающие заявки пользователя в этом проекте закрываются.
- **Matching помогает принять решение.** Он объясняет соответствие навыков, без ML и сложного процента.
- **Общение — за пределами сервиса.** Встроенный чат не входит в v1.

## Архитектура

**Модульный монолит:** предметные области организуются внутри одного backend-приложения.

Целевая схема взаимодействия:

```text
Frontend
   │
   ▼
API / Controllers
   │
   ▼
Services · бизнес-логика
   │
   ▼
Entity Framework Core
   │
   ▼
PostgreSQL
```

### Целевой технологический стек

> Таблица описывает выбранные технологии и их назначение. Она не означает, что все компоненты уже подключены или реализованы.

| Технология | Назначение в архитектуре |
| :--- | :--- |
| **C# · ASP.NET Core** | Backend и HTTP API |
| **Entity Framework Core** | Работа с данными и миграции |
| **PostgreSQL** | Реляционная база данных |
| **Swagger / OpenAPI** | Описание и исследование API |
| **Docker** | Контейнеризация и воспроизводимое окружение |
